# 0004. Only claims we can stand behind

Status: Accepted
Date: 2026-10-01

## Context

Marketing sites love stat rows: clients served, satisfaction rates, hours
saved. A prospect who checks one inflated number stops trusting the rest of
the page.

## Decision

The site states only figures and claims we can evidence. If a number cannot be
sourced, the copy makes the point without one. No stat rows for their own sake.

## Consequences

- Copy reads less "salesy" and survives scrutiny.
- Testimonials and portfolio entries must be real; see
  [0009](0009-real-portfolio-imagery.md).
